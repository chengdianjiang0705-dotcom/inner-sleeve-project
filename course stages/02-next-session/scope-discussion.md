- Music streaming or hosting complete songs.
- A complete catalogue or detailed biography for every artist.

## Points to discuss in class

- Does the four-page route give a first-time listener enough context without too much reading?
- Can each artist portrait use the same structure while keeping a distinct visual mood?
- Are one focus song and three entry songs per artist a manageable content scope?
- Which simple JavaScript interaction best supports the listening guide?
- Which later course exercises should remain supporting pages?

These are prepared discussion points and recorded scope choices, not a claim that a classroom discussion has already happened.
